Проект рассчитан на **4 этапа (квартала)**: от первичного анализа данных и классического baseline до промышленных гибридных архитектур и систем переранжирования (reranking).

## Этап 1: EDA, обработка данных и базовая валидация (Q1)

**Цель:** Подготовить инфраструктуру, провести разведочный анализ данных (EDA), сформировать пайплайны валидации и получить первые базовые скоры.

* **Работа с данными:**
* Анализ структуры транзакций (длина пользовательских сессий, распределение по времени, разреженность матриц взаимодействия).
* Предобработка: фильтрация коротких сессий (менее 3–5 транзакций), очистка редких товаров, кодирование категориальных признаков.
* Формирование временного сплита (Temporal Train/Validation/Test Split) для исключения утечки данных из будущего (data leakage).


* **Метрики качества:**
1. **MRR@K (Mean Reciprocal Rank)** — оценивает позицию первой правильной рекомендации.
2. **NDCG@K (Normalized Discounted Cumulative Gain)** — учитывает ранжирование с дисконтированием по позиции.
3. **Recall@K (Hit Rate)** — доля релевантных товаров, попавших в Топ-K.
4. **Precision@K** — точность списка из K рекомендаций.
5. **Coverage (Item Coverage / Diversity)** — покрытие каталога товаров и разнообразие выдачи.

## Этап 2: Итерации моделей и эксперименты (Q2–Q3)

Ниже представлен перечень из **10 моделей**, распределенных от простых эвристик до современных глубоких последовательных архитектур (Sequential Recommenders).

### 1. Collaborative / Session Baseline Models

* **Most Popular / Time-decayed Popularity:** Простейший бейзлайн на основе популярных товаров с угасанием веса от времени.
* **Item-KNN / Co-occurrence Matrix:** Фильтрация на основе совстречаемости товаров в транзакционных корзинах за окно $T$.
* **S-KNN (Session-based KNN):** Метод ближайших соседей для сессий — находит похожие транзакционные сессии других пользователей и рекомендует их продолжение.

### 2. Matrix Factorization & Graph Models

* **ALS (Implicit Alternating Least Squares):** Матричная факторизация для неявного отклика (implicit feedback) с весами частоты транзакций.
* **LightGCN:** Графовая нейронная сеть (GNN), моделирующая связи «пользователь-товар» в виде двудольного графа через сглаживание эмбеддингов.

### 3. Sequential & Recurrent Neural Models

* **GRU4Rec:** Рекуррентная сеть (GRU) для моделирования динамики сессий транзакций.
* **Caser (Convolutional Sequence Embeddings):** Сверточная модель, обрабатывающая транзакционную последовательность с помощью 1D и 2D сверток для захвата коротких шаблонов покупок.

### 4. Attention & Transformer-based Models

* **SASRec (Self-Attention Sequential Recommendation):** Однонаправленный трансформер на основе селф-аттеншна, фиксирующий долговременные и короткоживущие интересы по цепи транзакций.
* **BERT4Rec:** Двунаправленный трансформер с использованием Masked Language Model (MLM) таски для предсказания пропущенных/следующих транзакций.

### 5. Multi-Stage Hybrid Models

* **Two-Stage Architecture (Candidate Generation + Ranker):**
* **1-й этап (Retrieval):** Быстрый отбор 100–500 кандидатов (например, SASRec / ALS + FAISS / HNSW).
* **2-й этап (Reranking):** Gradient Boosting (CatBoost / LightGBM) с признаками транзакционного профиля, времени, категорий и текстовых метаданных товаров.

## Этап 3: Двухстадийная архитектура пайплайна (Q3)

На этом этапе лучшие модели объединяются в промышленную двухэтапную схему (Retrieval + Ranking).

1. **Candidate Generation (Retrieval):**
Использование быстрых векторных индексов (FAISS / HNSW) над эмбеддингами SASRec и LightGCN для отбора Top-200 кандидатов за $O(\log N)$.


2. **Feature Engineering:**
Генерация динамических признаков: время с последней покупки, частота категорий в транзакциях, агрегаты чека, популярность товара в текущем окне.


3. **Reranking Stage:**
Обучение CatBoost / LightGBM с оптимизацией ранжирующих лоссов (pairwise / listwise, e.g., YetiRank или LambdaMART).


4. **Post-processing & Business Rules:**
Диверсификация выдачи (MMR — Maximal Marginal Relevance), дедупликация и фильтрация уже купленных товаров.

## Этап 4: Финализация, мульти-метрический анализ и отчетность (Q4)

**Цель:** Сведение результатов всех 10 моделей в единую сравнительную таблицу, анализ trade-off между точностью и разнообразием.

* **Экспериментальное сравнение:**
* Построение финальной сравнительной таблицы по метрикам NDCG@10, Recall@10, MRR@10, Precision@10 и Coverage на тестовом временном сплите.
* Анализ холодных пользователей (Cold Start) и редких товаров (Long Tail).


* **Профилирование скорости (Latency Benchmark):**
* Замер времени инференса на одну сессию (ms) для каждого кандидата в продакшен.


* **Оформление результатов:**
* Подготовка репозитория (структурированный код, Hydra конфиги, DVC пайплайны).
* Финальный текстовый отчет и презентация работы.
